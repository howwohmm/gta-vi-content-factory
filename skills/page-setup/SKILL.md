# Page setup for a GTA VI clips page

Goal: one brand on every platform, all linking to each other, so followers on one find the others.

## Ask first
- Page name and handle they want (check availability on each platform before suggesting).
- Whether they already have any of the accounts.
Get a yes before creating anything, changing a bio, or accepting any terms. Never type passwords or verification codes; the user does sign-ins.

## Checklist
1. **Instagram**: Professional (Creator or Business) account; bio = what the page posts in one line ("the funniest things you can do in GTA VI, daily"); link in bio → YouTube channel (or a link page listing all).
2. **Facebook Page**: same name and profile picture; link the Instagram account (Page settings → Linked accounts). In Instagram → Accounts Center → Sharing across profiles, the user can turn on automatic reel sharing to the Page (keeps Instagram + Facebook analytics merged).
3. **Threads**: created from the Instagram account; same bio.
4. **YouTube**: channel name = page name; Customisation → Basic info: description + links to Instagram, Threads, X; Settings → Upload defaults: description with links, visibility, category Gaming; Settings → Channel → Feature eligibility → verify phone/advanced features (lifts the daily upload limit).
5. **X (optional)**: same handle; pinned post linking the YouTube channel.

## Profile picture and banner
Use the user's own artwork or a design they approve. Don't use the official game logo or key art as the page's own branding without telling the user that it can draw takedown requests; suggest an original design instead.

## Finish
Give the user a list of every profile URL so they can add them to the factory's caption templates (Settings → Captions).
